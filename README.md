# Mini_project_2_ESP-IDF

Навчальний проєкт для ESP32-S3 на C++ та ESP-IDF, зібраний у PlatformIO / VS Code.
Програма обробляє чотири кнопки, керує індикаторами й реле, розпізнає коротке, довге та подвійне натискання. Обробка побудована на подіях і черзі FreeRTOS.

## Документація

- [Електрична схема](docs/Mini_project_module_2.jpg)
- [FSM — діаграми станів обробки кнопок](docs/README.md). У **VS Code** відкрийте [docs/README.md] і натисніть **Ctrl+Shift+V**, щоб побачити діаграму.


## Керування

- SW1 - Коротке натискання - Перемикання стану контролера дверей (реле)
- SW1 - Довге натискання - Valet: вихід з аварійного режиму, скидання аварійки, поворотів і червоних індикаторів; реле залишається ввімкненим 
- SW2 - Коротке натискання - Увімкнення / вимкнення аварійного блимання 
- SW3 - Коротке натискання - Перемикання лівого повороту; правий вимикається 
- SW3 - Подвійне натискання - Перемикання правого повороту; лівий вимикається 
- SW4 - Коротке натискання - Увімкнення / вимкнення червоних індикаторів 
- SW4 - Довге натискання - Вхід в аварійний режим 


## Збірка та запуск у VS Code

У панелі **PlatformIO → PROJECT TASKS → esp32-s3-devkitc-1**:

1. **Build** — зібрати прошивку.
2. **Upload** — завантажити її на плату.
3. **Monitor** — відкрити монітор повідомлень.
